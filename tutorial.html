O que é Git?

O Git é um sistema de controle de versão que permite acompanhar as mudanças feitas em um projeto. Com ele, podemos salvar versões do nosso código, voltar a versões anteriores e trabalhar em equipe.

Neste tutorial, você vai aprender os comandos básicos para começar a usar o Git nos seus projetos.

Passo 1 - Instalar o Git

Primeiro, precisamos instalar o Git no computador. Para isso, acesse o site oficial e baixe a versão compatível com o seu sistema operacional.

Site oficial: Baixar Git

Depois de instalar, abra o Git Bash ou o terminal do seu computador para começar a utilizar os comandos.

Passo 2 - Configurar o Git

Antes de começar, precisamos configurar nosso nome e e-mail. Essas informações serão utilizadas para identificar quem fez cada alteração no projeto. 

git config --global user.name "Seu Nome"
git config --global user.email "seuemail@exemplo.com"

Substitua "Seu Nome" pelo seu nome e o e-mail pelo endereço que deseja utilizar.

Passo 3 - Criar uma pasta para o projeto

Crie uma pasta no computador para guardar os arquivos do seu projeto. Depois, abra o terminal nessa pasta. No Windows, você também pode abrir o terminal e navegar até a pasta usando o comando cd. 

cd nome-da-pasta

Troque "nome-da-pasta" pelo nome da pasta que você criou.

Passo 4 - Iniciar o Git

Agora, vamos iniciar o Git dentro da pasta do projeto. Esse comando cria um repositório Git, que permite acompanhar as alterações dos arquivos. 

git init

Pronto! A pasta agora possui um repositório Git.

Passo 5 - Verificar as alterações

Depois de criar ou modificar arquivos, podemos verificar quais alterações foram feitas utilizando o comando git status. 

git status

Ele mostra os arquivos novos, modificados e aqueles que ainda não foram preparados para serem salvos.

Passo 6 - Preparar os arquivos

Para selecionar os arquivos que queremos incluir no próximo salvamento, utilizamos o comando git add. 

git add .

O ponto significa que todos os arquivos e alterações da pasta atual que não forem ignorados pelo Git serão adicionados à área de preparação.

Passo 7 - Salvar as alterações

Agora vamos registrar as alterações selecionadas. No Git, esse registro é chamado de commit. Ele recebe uma mensagem explicando o que foi alterado. 

git commit -m "Primeiro commit"

A mensagem entre aspas pode ser modificada para descrever as alterações realizadas no projeto.

Passo 8 - Criar um repositório no GitHub

O GitHub é uma plataforma online que permite armazenar repositórios Git e compartilhar projetos com outras pessoas.

Acesse o site, faça login e clique em "New repository" para criar um novo repositório. Escolha um nome para o projeto e crie o repositório.

Site: Acessar GitHub

Passo 9 - Conectar o projeto ao GitHub

Depois de criar o repositório online, precisamos conectar a pasta do computador a ele. Copie o endereço HTTPS do repositório no GitHub e utilize os comandos abaixo. 

git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git

Substitua o endereço de exemplo pelo endereço do seu próprio repositório. O comando remote add cria a conexão entre o projeto local e o repositório online.

Passo 10 - Enviar o projeto

Para enviar os commits do computador para o GitHub, utilizamos o comando git push. 

git push -u origin main

Na primeira vez, pode ser necessário autenticar sua conta. Depois que o envio terminar, os arquivos e as alterações registradas estarão disponíveis no GitHub.

Passo 11 - Atualizar o projeto

Sempre que você modificar os arquivos e quiser salvar uma nova versão, pode repetir os comandos abaixo. 

git add .
git commit -m "Descreva as alterações"
git push

Se outras pessoas modificarem o repositório online, você pode buscar e integrar essas alterações usando git pull antes de continuar trabalhando. 

git pull

Principais comandos do Git

Comando Função Uso
git init Iniciar um repositório Cria um repositório Git na pasta do projeto
git status Verificar alterações Mostra os arquivos novos ou modificados
git add . Preparar arquivos Adiciona as alterações à área de preparação
git commit Registrar alterações Salva um registro das alterações selecionadas
git push Enviar alterações Envia os commits para o repositório remoto
git pull Atualizar o projeto Busca e integra alterações do repositório remoto
git log Consultar histórico Mostra o histórico de commits realizados

Conclusão

O Git é uma ferramenta muito útil para quem está aprendendo programação. Com seus comandos básicos, podemos organizar projetos, acompanhar mudanças e compartilhar nosso código com outras pessoas.
